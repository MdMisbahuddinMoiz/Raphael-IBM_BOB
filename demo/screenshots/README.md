# Demo Screenshots

Operator-captured UI screenshots belong here (PNG/JPG). They are optional for
submission but useful for judges.

Suggested captures (open the pages listed in
[`docs/DEMO_CHECKLIST.md`](../../docs/DEMO_CHECKLIST.md)):

1. `/operations` — the Operations console before starting.
2. `/operations/{run_id}` — the success run overview.
3. `/operations/{run_id}/decision-trace` — the A–G checklist (7/7).
4. `/operations/{run_id}/evidence` — the independent probe + regression records.
5. `/operations/{refusal_run_id}/decision-trace` — the refusal (6/7, D FAIL).

The demo does not depend on screenshots; the machine-readable
[`../success/`](../success) and [`../refusal/`](../refusal) bundles are the
authoritative evidence.
