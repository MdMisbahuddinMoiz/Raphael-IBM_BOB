# M10.1 — Durable Runs + Evidence Persistence

## Where runs are stored

```text
runs/<run_id>/
    evidence.jsonl
    artifacts/
```

`runs/` is repository-local. Generated run contents are git-ignored
(`runs/*`, see `.gitignore`); only the mechanism (`runs/`, plus this
doc) is tracked via `runs/.gitkeep`. Decision: reproducibility comes
from the mechanism, not from checking runtime artifacts into Git.

## How run IDs work

`raphael_bob.evidence_ledger.generate_run_id()` builds
`<UTC-timestamp>_<6-hex>`, e.g. `20260915T094736_106e3e`. The stamp
orders runs; the random suffix makes same-second starts collision
resistant. `create_run_dir(base)` creates `<base>/<run_id>/` with
mkdir-without-exist (a collision is retried, never appended to), so
two runs never share a ledger. Run IDs are infrastructure labels,
not evidence: never compare them for determinism.

## Where evidence.jsonl lives

`EvidenceLedger(run_dir)` is unchanged (M3 semantics: request,
decision, result, evidence, finding, gate; dense per-run sequences
starting at 1). The only change is who picks `run_dir`: the hero now
calls `create_run_dir(ROOT / "runs")` instead of `tempfile.mkdtemp`,
so the authoritative record is generated in the durable location —
nothing is copied from `/tmp` after the fact. `EvidenceLedger.close()`
was added for lifecycle hygiene; every append was already
fsync-durable, so a reopened reader sees all records regardless.

## Where artifacts live

`runs/<run_id>/artifacts/<evidence_id>.json`, referenced by each
`ResultRecord.artifact_ref`. The QualityGate resolves these paths
when checking `returncode == 0`; because they sit under the run dir,
a reopened run is self-sufficient.

## How to reopen a run

```python
from pathlib import Path
from raphael_bob.evidence_ledger import LedgerReader

reader = LedgerReader(Path("runs/<run_id>/evidence.jsonl"))
kinds = [r["kind"] for r in reader.records()]
gates = reader.gate_decisions()   # final verdict + checks + refs
chain = reader.by_request_seq(n)  # causal slice per request
```

No live objects from the original process are needed. The hero prints
`Run ID:`, `Evidence: runs/<id>/evidence.jsonl`, and `Gate:` so a run
can be located from console output alone.

## Out of scope (later M10)

`metrics.json`, benchmark aggregation, `PROVENANCE.md`,
submission-checklist, demo-runbook, packaging. M10.1 only makes
existing proof durable.
